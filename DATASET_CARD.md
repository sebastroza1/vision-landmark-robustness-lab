# Dataset Card: Synthetic Geometric Landmarks

- Creator: Sebastián Astroza, generated by the code in this repository
- License: MIT with the repository
- Type: synthetic numeric arrays; 12 two-dimensional points per sample
- Labels: `balanced_pattern` and `perturbed_pattern`
- Personal or clinical data: none
- Redistribution: generator code and small generated run artifacts may be redistributed under MIT

Every sample begins from the same abstract bilateral geometry, receives small random jitter and global rotation/scale/translation, and half receive one or two extra right-side point perturbations. The names of points provide a facial-geometry analogy, but samples are not extracted from faces and labels do not represent health states.

Quick mode independently generates 2,400 training, 600 validation, and 1,000 test samples from seeds 42, 43, and 44. This prevents sample overlap but does not create real-world diversity. The controlled generator can make the task easier and cleaner than any image-derived landmark problem.
